3. A level is data, not another scene

LEVELS is an array: an ordered list. Each item is a dictionary: a bundle of named values. name is the HUD title, start is the comet spawn, energy is the starting budget and refill cap, and slots holds planet placements.

const LEVELS: Array[Dictionary] = [
	{"name": "First Light", "start": Vector2(200, 200), "energy": 100.0,
	"slots": [Vector3(400, 250, 60), Vector3(1450, 300, 80), Vector3(450, 800, 50), Vector3(1450, 800, 60)]},
	{"name": "Slingshot", "start": Vector2(168, 960), "energy": 85.0,
	"slots": [Vector3(480, 264, 62.4), Vector3(720, 864, 62.4), Vector3(1344, 216, 76.8), Vector3(1560, 600, 57.6), Vector3(1248, 912, 62.4)]},
	{"name": "Ring", "start": Vector2(192, 540), "energy": 70.0,
	"slots": [Vector3(600, 216, 57.6), Vector3(600, 864, 57.6), Vector3(1344, 216, 57.6), Vector3(1344, 864, 57.6), Vector3(960, 144, 48), Vector3(960, 948, 48)]}
]

In each Vector3(x, y, radius), x moves right and y moves down. The third number is a radius, not depth: this remains a 2D game. A radius of 60 produces a 120-pixel-wide image. The first slot uses Earth, then Jupiter, Mars, Neptune, Venus and Mercury.

The first level keeps your layout. The other two adapt the existing Slingshot and Ring plan to 1920×1080 by multiplying its coordinates and radii by 2.4.

Code/groupPlain meaning
func load_level(index: int)Define a function that receives a whole-number level index. Arrays start at zero, so 0 means Level 1.
level_index = indexRemember which stage is active so Retry knows where to return.
LEVELS[index]Read that stage's dictionary.
planets.clear()Empty the active physics list. This does not delete scene nodes or image files.
for sprite ... hide()Hide all six reusable images before deciding which this stage uses.
for slot_index in range(...size())Repeat once for each planet placement.
slot / spriteRead this placement and select its corresponding image node.
sprite.positionPlace the centre at the requested x and y.
sprite.scaleDivide the desired diameter by the image dimensions to calculate its scale.
sprite.modulateDarken the planet to 25% brightness.
planets.append(...)Add the node, collision radius and unlit flag to the list used by gravity, collisions and relighting.
comet_position through hot_timeMove to this level's starting point and clear motion, the old drag and heat.
energy_limit / energyRead this level's budget and fill it. Relight refunds also stop at this limit.
run_active / resume_screenA fresh unfinished level exists and Continue should return to gameplay.
Label / bar assignmentsImmediately display the new budget, zero lit planets and the level title.
show_screen("play")Show the active planets, dismiss menus and allow physics to run.

5. One button, three possible actions

func result_action() -> void:

		load_level(level_index + 1)

		load_level(level_index)
	elif screen == "won":

if tests the current screen. On cleared, add one to the level index and load it. elif means “otherwise, if”: on lost, reload the same index. On the final won screen, start a fresh campaign.

func start_run() -> void:
	load_level(0)

Fresh Play always loads index 0. Retry is deliberately different: it retains the current index.

6. Clearing a stage versus finishing the game

func show_result(won: bool) -> void:
	var more_levels: bool = won and level_index + 1 < LEVELS.size()
	run_active = more_levels
	$GameOverPanel/Title.text = "Level complete!" if more_levels else ("All planets lit!" if won else "Out of energy")
	$GameOverPanel/Message.text = "Ready for Level %d?" % (level_index + 2) if more_levels else ("You completed all three levels." if won else "Try this level again with fresh energy.")
	$GameOverPanel/Retry.text = "Next Level" if more_levels else ("Play Again" if won else "Retry Level")
	show_screen("cleared" if more_levels else ("won" if won else "lost"))

more_levels is true only if all planets are lit and another level exists. The form A if condition else B chooses A when the condition is true and B otherwise. That selects the panel text and button label.

An intermediate clear keeps run_active true. Home remembers the cleared screen, so Continue still shows Next Level. A final win makes it false, so Home offers a fresh Play.

7. The drawing helper

func _draw() -> void:
	GameView.draw_game(self)

preload near the top of game.gd loads the helper script. self means the current Game node. Godot calls Game's _draw(); the helper then uses that node's draw functions. It is not a new scene or a new moving object.

In game_view.gd, game.comet_position reads Game's current comet position. game.draw_circle(...) draws on the same Game node as before. Keeping drawing here lets game.gd stay below 400 lines without changing the physics.

func _physics_process(delta: float) -> void:
	if screen != "play":
		return
	if is_aiming and not Input.is_mouse_button_pressed(MOUSE_BUTTON_LEFT):
		is_aiming = false
	var was_hot: bool = hot_time > 0.0
	bounce_cooldown = maxf(0.0, bounce_cooldown - delta)
	hot_time = maxf(hot_time - delta, 0.0)
	if was_hot and hot_time == 0.0:
		$CoolSound.play()
	move_comet(delta)
	if has_launched and bounce_cooldown == 0.0:
		for planet in planets:
			if comet_position.distance_to(planet["node"].position) <= planet["radius"] + 20.1:
				$BounceSound.play()
				bounce_cooldown = 0.15
				break

	if has_launched and hot_time > 0.0:
		for planet in planets:
			if planet["lit"]:
				continue

			var planet_node: Sprite2D = planet["node"]
			var radius: float = planet["radius"]
			var distance: float = comet_position.distance_to(planet_node.position)

			if distance <= radius + 20.0 + 0.1:
				$RelightSound.play()
				planet["lit"] = true
				planet_node.modulate = Color.WHITE
				energy = minf(energy + 15.0, energy_limit)
	var lit_count: int = planets.filter(func(planet: Dictionary) -> bool: return planet["lit"]).size()
	$PlanetsLabel.text = "Planets: %d / %d" % [lit_count, planets.size()]
	if lit_count == planets.size():
		show_result(true)
	elif hot_time <= 0.0 and energy + 0.000001 < MIN_SHOT_COST:
		show_result(false)
	$EnergyLabel.text = "Energy: %.1f / %d" % [energy, int(energy_limit)]
	$EnergyBar.value = energy
	if is_aiming:
		var shot_velocity: Vector2 = ((drag_start - get_local_mouse_position()) * 4.0).limit_length(630.0)

		if shot_velocity.length() >= 60.0:
			var power: float = shot_velocity.length() / 630.0
			var shot_cost: float = 10.0 + 20.0 * power
			$EnergyLabel.text += "   |   Shot cost: %.1f" % shot_cost

			if energy < shot_cost:
				$EnergyLabel.text += "   Not enough energy"
		else:
			$EnergyLabel.text += "   |   Drag farther to shoot"
	queue_redraw()

func preview_path(launch_velocity: Vector2) -> PackedVector2Array:
	var saved_position: Vector2 = comet_position
	var saved_velocity: Vector2 = comet_velocity
	var saved_launched: bool = has_launched

func move_comet(delta: float) -> void:
	if has_launched:
		var nearest_distance: float = INF

		for planet in planets:
			var planet_node: Sprite2D = planet["node"]
			var radius: float = planet["radius"]
			var to_planet: Vector2 = planet_node.position - comet_position
			var distance: float = to_planet.length()

			nearest_distance = minf(nearest_distance, distance)

			var size_factor: float = radius / 60.0
			var strength: float = gravity_strength * size_factor * size_factor
			var safe_distance: float = maxf(distance, 40.0)
			var pull: float = strength / (safe_distance * safe_distance)

			comet_velocity += to_planet.normalized() * pull * delta

		var far_amount: float = clampf((nearest_distance - 200.0) / 200.0, 0.0, 1.0)
		var slowdown: float = pow(0.5, delta * far_amount)
		comet_velocity *= slowdown

		var to_hole: Vector2 = hole_position - comet_position
		var hole_distance: float = maxf(to_hole.length(), 60.0)
		var hole_pull: float = minf(1600.0, 2000000.0 / (hole_distance * hole_distance))
		comet_velocity += to_hole.normalized() * hole_pull * delta
		var from_center: Vector2 = comet_position - hole_position
		var edge_fraction: float = maxf(absf(from_center.x) / 960.0, absf(from_center.y) / 540.0)
		var edge_depth: float = maxf((edge_fraction - 0.8) / 0.2, 0.0)
		var outward: Vector2 = from_center.normalized()
		var outward_speed: float = maxf(comet_velocity.dot(outward), 0.0)

		var border_pull: float = edge_depth * (150.0 + outward_speed * 3.0)
		border_pull += 700.0 * edge_depth * edge_depth
		comet_velocity -= outward * minf(border_pull, 6000.0) * delta

		comet_position += comet_velocity * delta
		bounce_off_planet()
		orbit_around_hole()
		assist_planet_orbit(delta)

func _unhandled_input(event: InputEvent) -> void:
	if screen == "intro":
		return
	if event is InputEventKey and event.pressed and not event.echo:
		if event.keycode == KEY_ESCAPE:
			show_screen("menu")
			return
		if event.keycode == KEY_R and screen in ["play", "cleared", "lost", "won"]:
			load_level(level_index)
			return
	if screen != "play":
		return
	if event is InputEventMouseButton:
		if event.button_index == MOUSE_BUTTON_LEFT:
			if event.pressed:
				drag_start = event.position
				is_aiming = true
			elif is_aiming:
				is_aiming = false

				var shot_velocity: Vector2 = ((drag_start - event.position) * 4.0).limit_length(630.0)

				if shot_velocity.length() < 60.0:
					return

				var power: float = shot_velocity.length() / 630.0
				var cost: float = 10.0 + 20.0 * power

				if energy < cost:
					$EnergyLabel.text = "Not enough energy for this shot"
					return

				$LaunchSound.play()
				energy -= cost
				comet_velocity = shot_velocity
				has_launched = true
				hot_time = 3.0

func bounce_off_planet() -> void:
	for planet in planets:
		var planet_node: Sprite2D = planet["node"]
		var radius: float = planet["radius"]
		var away: Vector2 = comet_position - planet_node.position
		var contact_distance: float = radius + 20.0

		if away.length() < contact_distance:
			var normal: Vector2 = away.normalized()

			if away.length_squared() == 0.0:
				normal = Vector2.RIGHT

			comet_position = planet_node.position + normal * contact_distance

			var inward_speed: float = comet_velocity.dot(normal)
			if inward_speed < 0.0:
				comet_velocity -= 1.9 * inward_speed * normal

func orbit_around_hole() -> void:
	var away: Vector2 = comet_position - hole_position
	var safe_radius: float = 110.0

	if away.length() >= safe_radius:
		return

	var outward: Vector2 = away.normalized()
	if away.length_squared() == 0.0:
		outward = Vector2.RIGHT

	var turn: float = 1.0
	if away.cross(comet_velocity) < 0.0:
		turn = -1.0

	comet_position = hole_position + outward * safe_radius

	var sideways: Vector2 = Vector2(-outward.y, outward.x) * turn
	var orbit_speed: float = clampf(comet_velocity.length(), 120.0, 220.0)
	comet_velocity = sideways * orbit_speed

func warp_point(point: Vector2) -> Vector2:
	var toward_hole: Vector2 = hole_position - point
	var distance: float = toward_hole.length()
	var bend: float = 168.0 * exp(-distance / 408.0)
	bend = minf(bend, distance * 0.8)
	return point + toward_hole.normalized() * bend

func assist_planet_orbit(delta: float) -> void:
	if comet_velocity.length() > 220.0:
		return

	for planet in planets:
		var planet_node: Sprite2D = planet["node"]
		var radius: float = planet["radius"]
		var away: Vector2 = comet_position - planet_node.position
		var distance: float = away.length()

		if distance < 1.0 or distance > radius * 3.0:
			continue

		var outward: Vector2 = away.normalized()
		var turn: float = 1.0
		if away.cross(comet_velocity) < 0.0:
			turn = -1.0

		var sideways: Vector2 = Vector2(-outward.y, outward.x) * turn

		var size_factor: float = radius / 60.0
		var strength: float = gravity_strength * size_factor * size_factor
		var orbit_speed: float = clampf(sqrt(strength / distance), 70.0, 150.0)
		var target_velocity: Vector2 = sideways * orbit_speed

		if distance < radius + 40.0:
			target_velocity += outward * 60.0

		comet_velocity = comet_velocity.lerp(target_velocity, minf(2.0 * delta, 1.0))
		return

static func configure_result(game: Node2D, won: bool) -> void:
	var panel: Panel = game.get_node("GameOverPanel")
	panel.position = Vector2.ZERO
	panel.size = Vector2(1920, 1080)
	panel.get_node("DefeatArt").hide()
	panel.get_node("Details").visible = not won
	panel.get_node("Details").position = Vector2(300, 750)
	panel.get_node("Details").size = Vector2(1320, 85)
	var background := StyleBoxFlat.new()
	background.bg_color = Color(0.025, 0.025, 0.07)
	panel.add_theme_stylebox_override("panel", background)
	var animation: AnimatedSprite2D = panel.get_node("ResultAnimation")
	animation.stop()
	animation.play("victory" if won else "defeat")
	var layouts: Array[Rect2] = [Rect2(260, 90, 1400, 140), Rect2(300, 660, 1320, 90), Rect2(510, 900, 420, 110), Rect2(990, 900, 420, 110)]
	var names: Array[String] = ["Title", "Message", "Retry", "Home"]
	for i in range(names.size()):
		var control: Control = panel.get_node(names[i])
		control.position = layouts[i].position
		control.size = layouts[i].size
	for label: Label in [panel.get_node("Title"), panel.get_node("Message"), panel.get_node("Details")]:
		label.add_theme_constant_override("outline_size", 8)
		label.add_theme_color_override("font_outline_color", Color("091020"))
	panel.get_node("Title").add_theme_font_size_override("font_size", 90)
	if not won:
		panel.get_node("Title").text = "GAME OVER"
		panel.get_node("Message").text = "Out of energy. Retry this level with a fresh energy pool."
		var count: int = game.planets.filter(func(planet: Dictionary) -> bool: return planet["lit"]).size()
		panel.get_node("Details").text = "Level %d / %d · %s · %d / %d planets relit" % [game.level_index + 1, game.LEVELS.size(), game.LEVELS[game.level_index]["name"], count, game.planets.size()]

const LESSONS: Array[String] = ["One last spark.", "Pull left. Fly right.", "Hit a planet before the ring runs out.", "Spend energy. Earn it back with hits."]

static func setup_tutorial(game: Node2D) -> void:
	var canvas: Control = game.get_node("Tutorial")
	canvas.set_meta("page", 0)
	canvas.set_meta("time", 0.0)
	canvas.draw.connect(draw_tutorial.bind(canvas, game))
	canvas.get_node("Back").pressed.connect(turn_page.bind(game, -1))
	canvas.get_node("Next").pressed.connect(turn_page.bind(game, 1))
	canvas.get_node("Home").pressed.connect(game.show_screen.bind("menu"))
	var animation: Tween = game.create_tween().set_loops()
	animation.tween_method(func(time: float) -> void: canvas.set_meta("time", time); canvas.queue_redraw(), 0.0, 5.0, 5.0)
	canvas.set_meta("animation", animation)
	animation.pause()
	canvas.visibility_changed.connect(func() -> void: animation.play() if canvas.visible else animation.pause())

static func open_tutorial(game: Node2D) -> void:
	game.get_node("Tutorial").set_meta("page", 0)
	game.get_node("Tutorial").set_meta("time", 0.0)
	game.get_node("Tutorial/Next").text = "Next"
	game.show_screen("tutorial")
	game.get_node("Tutorial").get_meta("animation").stop()
	game.get_node("Tutorial").get_meta("animation").play()

static func turn_page(game: Node2D, direction: int) -> void:
	var canvas: Control = game.get_node("Tutorial")
	var page: int = canvas.get_meta("page") + direction
	if page < 0:
		game.show_screen("menu")
	elif page > 3:
		game.continue_run() if game.run_active else game.start_run()
	else:
		canvas.get_meta("animation").stop()
		canvas.get_meta("animation").play()
		canvas.set_meta("page", page)
		canvas.set_meta("time", 0.0)
		canvas.get_node("Next").text = "Next" if page < 3 else ("Continue" if game.run_active else "Play")
		canvas.queue_redraw()

static func lesson_text(canvas: Control, y: float, text: String, size: int = 16, color: Color = Color("eee6fc")) -> void:
	canvas.draw_set_transform(Vector2.ZERO, 0.0, Vector2.ONE)
	canvas.draw_string(HEADING_FONT if size >= 21 else BODY_FONT, Vector2(0, y * 2.4), text, HORIZONTAL_ALIGNMENT_CENTER, 1920, int(size * 2.4), color)
	canvas.draw_set_transform(Vector2.ZERO, 0.0, Vector2.ONE * 2.4)

static func lesson_planet(canvas: Control, game: Node2D, at: Vector2, radius: float, lit: bool) -> void:
	var tint := Color.WHITE if lit else Color(0.25, 0.25, 0.25)
	if lit:
		canvas.draw_circle(at, radius + 7, Color(0.4, 0.9, 0.85, 0.15))
	canvas.draw_texture_rect(game.get_node("Planet").texture, Rect2(at - Vector2.ONE * radius, Vector2.ONE * radius * 2), false, tint)

static func lesson_comet(canvas: Control, at: Vector2, hot: float) -> void:
	for i in range(8):
		canvas.draw_circle(at - Vector2(i * 5, 0), 7.0 - i * 0.65, Color(1.0, 0.72, 0.42, 0.5 - i * 0.055))
	canvas.draw_circle(at, 7, Color("fff3c4"))
	if hot > 0:
		canvas.draw_arc(at, 17, -PI / 2, -PI / 2 + hot * TAU, 48, Color("ffcf72"), 2, true)

static func draw_tutorial(canvas: Control, game: Node2D) -> void:

		lesson_comet(canvas, Vector2(400, 175), 1.0)

			canvas.draw_line(Vector2(x - 12, 175), Vector2(x + 12, 175), Color("68e6db"), 2)
			canvas.draw_line(Vector2(x + 5, 168), Vector2(x + 12, 175), Color("68e6db"), 2)

	else:

		for i in range(4):
			var x: float = 145.0 + i * 165

			canvas.draw_string(BODY_FONT, Vector2((x - 65) * 2.4, 269 * 2.4), str(values[i]), HORIZONTAL_ALIGNMENT_CENTER, 130 * 2.4, 50, Color("eee6fc"))

static func draw_game(game: Node2D) -> void:
	if game.screen not in ["play", "cleared", "lost", "won"]:
		return
	for x in range(0, 1921, 96):
		var points := PackedVector2Array()
		for y in range(0, 1081, 24):
			points.append(game.warp_point(Vector2(x, y)))
		game.draw_polyline(points, Color(0.63, 0.47, 1.0, 0.18), 1.0, true)

	for y in range(0, 1081, 96):
		var points := PackedVector2Array()
		for x in range(0, 1921, 24):
			points.append(game.warp_point(Vector2(x, y)))
		game.draw_polyline(points, Color(0.63, 0.47, 1.0, 0.18), 1.0, true)

	game.draw_circle(game.hole_position, 54.0, Color(0.6, 0.3, 0.9))
	game.draw_circle(game.hole_position, 46.0, Color.BLACK)
	game.draw_circle(game.comet_position, 20.0, Color.WHITE)
	if game.hot_time > 0.0:
		var heat_fraction: float = game.hot_time / 3.0
		var start_angle: float = -PI / 2.0
		var end_angle: float = start_angle + TAU * heat_fraction
		game.draw_arc(game.comet_position, 30.0, start_angle, end_angle, 64, Color(1.0, 0.8, 0.3), 3.0, true)
	if game.is_aiming:
		var mouse_position: Vector2 = game.get_local_mouse_position()
		var launch_velocity: Vector2 = ((game.drag_start - mouse_position) * 4.0).limit_length(630.0)
		var predicted_points: PackedVector2Array = game.preview_path(launch_velocity)

		for dot_position in predicted_points:
			game.draw_circle(dot_position, 3.0, Color(1.0, 1.0, 1.0, 0.6))

11. Sound effects

The scene now has four AudioStreamPlayer nodes directly under Game: LaunchSound, RelightSound, ClearSound and LoseSound. Each has a stream from assets/audio, volume 0 dB and autoplay off. These reuse the original game's project-generated sounds; no downloaded audio or music was added.

$LaunchSound.play()

The dollar sign finds the node named LaunchSound under Game. The dot accesses its function. play() starts its assigned audio stream. This line runs only after the drag passes the minimum size and energy checks.

$RelightSound.play()

This runs when a hot comet lights a previously dark planet. It is outside move_comet(), so the dotted preview cannot trigger it. An already-lit planet skips this code.

if won:
    $ClearSound.play()
else:
    $LoseSound.play()

show_result() plays the clear chord for either a level clear or final victory. Otherwise it reuses the original falling swallow tone for Out of energy. The learning game still does not swallow the comet.

for player: AudioStreamPlayer in [$LaunchSound, $RelightSound, $ClearSound, $LoseSound]:
    player.stop()

load_level() stops all previous effects before a retry or new stage. The scene allows overlapping voices so quick shots or nearby relights do not unnecessarily cut each other off.

Try: F5 → Play → shoot → hit a dark planet. Clear a stage to hear the chord, or spend energy and wait for the ring to expire to hear the falling tone. Automated tests check stream loading and triggers; only your listening check can confirm volume and taste on your speakers.

14. Loud music that makes room for effects

Open Godot's Audio panel at the bottom. The saved default_bus_layout.tres defines Master, Music and Effects buses. A bus is a mixer channel. Every effect player sends to Effects; the song sends to Music; both reach Master.

Music has an AudioEffectCompressor whose sidechain is Effects. That means it listens to effect audio and turns the music down while effects are present. The song stays at 0 dB otherwise. Attack is 2000 microseconds (2 ms), release is 350 ms, threshold is -30 dB and ratio is 8. No additional gameplay code or timer is needed; overlapping effects also trigger it.

Source for this technique: Godot AudioEffectCompressor documentation.

The standalone music_duck_test.gd measured a steady test signal on the actual Music bus: RMS 0.1769 normally, 0.0093 during a clear effect, and 0.1754 after recovery. The test signal is only in the test; the game still plays Felitsa.
